Mass QR Sheet

Fill a grid with links, print one page, pin it to the board. Codes resize to fill the sheet, so the layout you see is the layout that prints.

×

In the print dialog pick the same paper size as above, set Margins to None and Scale to 100%. Anything else and the browser rescales the sheet, so the codes print at the wrong physical size.
