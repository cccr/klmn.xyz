# mass-qr Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/tools/mass-qr/`, a printable sheet of labelled QR codes laid out in an explicit grid that fits exactly one page.

**Architecture:** One Hugo layout file holding markup, CSS and vanilla JS, following the pattern of the two existing tools. The sheet is sized in real millimetres and laid out with CSS grid, so the same stylesheet drives both the on-screen preview and the printed page and no JavaScript layout math exists. Sheet state lives in a single object serialized to the URL hash. QR codes render as SVG through a renderer shared with the existing single-code tool.

**Tech Stack:** Hugo (static, no asset pipeline), Tailwind via CDN, vanilla ES5-style JS in an IIFE, Project Nayuki's `qrcodegen` (MIT, already vendored). Tests: Node's built-in runner (`node --test`) with `jsdom` and `jsqr`.

**Spec:** `docs/superpowers/specs/2026-09-19-mass-qr-design.md`

## Global Constraints

- **No build step.** No bundler, no transpiler, no framework. Scripts are plain classic scripts; CSS is hand-written plus Tailwind utility classes from the CDN.
- **No root `package.json`.** Netlify auto-runs `npm install` when it finds one at the repo root, which would change the deploy. All test tooling lives in `test/`.
- **Hugo version:** local `0.158.0`, Netlify pinned `0.147.8` in `netlify.toml`. Use nothing newer than 0.147 supports.
- **JS style:** match the existing tools — `(function () { 'use strict'; … })()`, `var`, no ES modules, no optional chaining. These files are served raw to browsers.
- **Vendored library is untouched.** `static/tools/qr/qrcodegen.js` keeps its MIT header and is never edited.
- **Attribution:** every page rendering QR codes carries the "QR encoding by Project Nayuki's qrcodegen (MIT)" credit line.
- **Print output carries no chrome:** no sheet title, subtitle, footer, or tile borders. These were explicitly ruled out in the spec's non-goals.
- **Redirect rules need `force = true`** in `netlify.toml`, or the Hugo alias file shadows them.
- **Defaults for a fresh sheet:** 2×2, A4 portrait, ECC `Q`, caption above at medium, `#000000` on `#ffffff`.

'use strict';
const fs = require('fs');
const path = require('path');
const { execFileSync } = require('child_process');
const { JSDOM } = require('jsdom');
const jsQR = require('jsqr');

const ROOT = path.resolve(__dirname, '..');
const SITE = path.join(ROOT, 'public');

function buildSite() {
  execFileSync('hugo', ['--quiet', '--source', ROOT], { stdio: 'inherit' });
}

function hexToRgb(h) {
  return [parseInt(h.substr(1, 2), 16), parseInt(h.substr(3, 2), 16), parseInt(h.substr(5, 2), 16)];
}

// Minimal 2d context: only fillStyle + fillRect, which is all the tools use.
function attachCanvas(window, canvas) {
  let ctx = null;
  Object.defineProperty(canvas, 'width', { get() { return this._w || 0; }, set(v) { this._w = v; this._buf = null; } });
  Object.defineProperty(canvas, 'height', { get() { return this._h || 0; }, set(v) { this._h = v; this._buf = null; } });
  canvas.getContext = function () {
    if (ctx) return ctx;
    ctx = {
      fillStyle: '#000000',
      fillRect(x, y, w, h) {
        const W = canvas.width, H = canvas.height;
        if (!canvas._buf || canvas._buf.length !== W * H * 4) canvas._buf = new Uint8ClampedArray(W * H * 4);
        const [r, g, b] = hexToRgb(this.fillStyle);
        for (let yy = y; yy < y + h; yy++) for (let xx = x; xx < x + w; xx++) {
          if (xx < 0 || yy < 0 || xx >= W || yy >= H) continue;
          const i = (yy * W + xx) * 4;
          canvas._buf[i] = r; canvas._buf[i + 1] = g; canvas._buf[i + 2] = b; canvas._buf[i + 3] = 255;
        }
      }
    };
    return ctx;
  };
  canvas.toBlob = (cb) => cb({ __png: true });
}

function decodeCanvas(canvas) {
  if (!canvas.width || !canvas._buf) return null;
  const res = jsQR(canvas._buf, canvas.width, canvas.height);
  return res && res.data;
}

// Rasterizes the "M x,y h1v1h-1z" path format our renderer emits, then decodes it.
function decodeSvgString(svg, scale) {
  scale = scale || 6;
  const n = parseInt(svg.match(/viewBox="0 0 (\d+) \1"/)[1], 10);
  const bg = hexToRgb(svg.match(/<rect[^>]*fill="(#[0-9a-fA-F]{6})"/)[1]);
  const fg = hexToRgb(svg.match(/<path[^>]*fill="(#[0-9a-fA-F]{6})"/)[1]);
  const W = n * scale;
  const buf = new Uint8ClampedArray(W * W * 4);
  for (let i = 0; i < W * W; i++) { buf[i * 4] = bg[0]; buf[i * 4 + 1] = bg[1]; buf[i * 4 + 2] = bg[2]; buf[i * 4 + 3] = 255; }
  const d = svg.match(/<path d="([^"]*)"/)[1];
  const re = /M(\d+),(\d+)h1v1h-1z/g;
  let m;
  while ((m = re.exec(d))) {
    const x = +m[1] * scale, y = +m[2] * scale;
    for (let yy = y; yy < y + scale; yy++) for (let xx = x; xx < x + scale; xx++) {
      const i = (yy * W + xx) * 4;
      buf[i] = fg[0]; buf[i + 1] = fg[1]; buf[i + 2] = fg[2];
    }
  }
  const res = jsQR(buf, W, W);
  return res && res.data;
}

// Loads a built page and runs its scripts. External srcs resolve against public/.
function loadPage(relPath) {
  const file = path.join(SITE, relPath);
  const html = fs.readFileSync(file, 'utf8');
  const dom = new JSDOM(html, { runScripts: 'outside-only', pretendToBeVisual: true });
  const { window } = dom;
  const doc = window.document;

  // jsdom does not expose these on window; the state codec needs them.
  window.TextEncoder = TextEncoder;
  window.TextDecoder = TextDecoder;

  const canvas = doc.querySelector('canvas');
  if (canvas) attachCanvas(window, canvas);

  // External scripts first, in document order, then inline ones.
  // qrcodegen.js declares `var qrcodegen` under "use strict", which a strict
  // eval scopes locally — re-export it so page scripts can see it.
  const EXPOSE = ';if(typeof qrcodegen!=="undefined"){window.qrcodegen=qrcodegen;}';
  doc.querySelectorAll('script[src]').forEach((s) => {
    const src = s.getAttribute('src').replace(/^\//, '');
    window.eval(fs.readFileSync(path.join(SITE, src), 'utf8') + EXPOSE);
  });
  doc.querySelectorAll('script:not([src])').forEach((s) => window.eval(s.textContent));

  const $ = (id) => doc.getElementById(id);
  const setInput = (el, v) => { el.value = v; el.dispatchEvent(new window.Event('input', { bubbles: true })); };
  const click = (el) => el.dispatchEvent(new window.Event('click', { bubbles: true }));

  return { dom, window, doc, $, setInput, click, canvas };
}

module.exports = { buildSite, loadPage, attachCanvas, decodeCanvas, decodeSvgString, hexToRgb, SITE, ROOT };
```

/*
 * Shared QR rendering helpers for klmn.xyz tools.
 * Depends on the global `qrcodegen` (Project Nayuki, MIT) being loaded first.
 */
(function (global) {
    'use strict';

    // Renders a QrCode as a standalone SVG document string. One <path> of
    // single-module subpaths keeps the file small; crispEdges stops the
    // renderer from anti-aliasing module boundaries into grey.
    function toSvgString(qr, quiet, fg, bg) {
        var n = qr.size + quiet * 2;
        var parts = [];
        for (var y = 0; y < qr.size; y++) {
            for (var x = 0; x < qr.size; x++) {
                if (qr.getModule(x, y)) {
                    parts.push('M' + (x + quiet) + ',' + (y + quiet) + 'h1v1h-1z');
                }
            }
        }
        return [
            '<?xml version="1.0" encoding="UTF-8"?>',
            '<svg xmlns="http://www.w3.org/2000/svg" version="1.1" viewBox="0 0 ' + n + ' ' + n + '" ' +
                'width="' + n + '" height="' + n + '" shape-rendering="crispEdges">',
            '\t<rect width="100%" height="100%" fill="' + bg + '"/>',
            '\t<path d="' + parts.join('') + '" fill="' + fg + '"/>',
            '</svg>',
            ''
        ].join('\n');
    }

    global.qrRender = { toSvgString: toSvgString };
})(typeof window !== 'undefined' ? window : globalThis);
```

This is a verbatim move of the function currently inside `qr.html`. Do not "improve" it — Task 2 must be behaviour-neutral.

    function clamp(n, lo, hi, dflt) {
        n = parseInt(n, 10);
        if (isNaN(n)) return dflt;
        return Math.min(hi, Math.max(lo, n));
    }

    function pickEnum(v, name, dflt) {
        return ENUMS[name].indexOf(v) === -1 ? dflt : v;
    }

    function hex(v, dflt) {
        return /^#[0-9a-fA-F]{6}$/.test(v) ? v.toLowerCase() : dflt;
    }

    function normalize(obj) {
        var d = defaultState();
        if (!obj || typeof obj !== 'object') return d;
        var s = {
            v: 1,
            rows: clamp(obj.rows, 1, MAX, d.rows),
            cols: clamp(obj.cols, 1, MAX, d.cols),
            paper: pickEnum(obj.paper, 'paper', d.paper),
            orient: pickEnum(obj.orient, 'orient', d.orient),
            ecc: pickEnum(obj.ecc, 'ecc', d.ecc),
            capPos: pickEnum(obj.capPos, 'capPos', d.capPos),
            capSize: pickEnum(obj.capSize, 'capSize', d.capSize),
            fg: hex(obj.fg, d.fg),
            bg: hex(obj.bg, d.bg),
            tiles: {}

        var tiles = obj.tiles || {};
        Object.keys(tiles).forEach(function (k) {
            var parts = k.split(',');
            var r = parseInt(parts[0], 10), c = parseInt(parts[1], 10);
            if (isNaN(r) || isNaN(c) || r < 0 || c < 0 || r >= s.rows || c >= s.cols) return;
            var t = tiles[k] || {};
            if (!t.u) return;
            s.tiles[key(r, c)] = { u: String(t.u), l: String(t.l || ''), d: String(t.d || '') };

        return s;

    // Built with a loop, not spread — a large sheet would blow the call stack.
    function encodeState(s) {
        var bytes = new TextEncoder().encode(JSON.stringify(s));
        var bin = '';
        for (var i = 0; i < bytes.length; i++) bin += String.fromCharCode(bytes[i]);
        return btoa(bin).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');

    function decodeState(str) {
        if (!str) return null;
        try {
            var b64 = String(str).replace(/-/g, '+').replace(/_/g, '/');
            while (b64.length % 4) b64 += '=';
            var bin = atob(b64);
            var bytes = new Uint8Array(bin.length);
            for (var i = 0; i < bin.length; i++) bytes[i] = bin.charCodeAt(i);
            var obj = JSON.parse(new TextDecoder().decode(bytes));
            if (!obj || obj.v !== 1) return null;
            return normalize(obj);

            return null;
        }

const CHROME = '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome';
const PORT = 8781;

// A sheet of four links, pre-loaded via the URL hash the app itself writes.
const STATE = {
  v: 1, rows: 2, cols: 2, paper: 'a4', orient: 'p', ecc: 'Q',
  capPos: 'above', capSize: 'm', fg: '#000000', bg: '#ffffff',
  tiles: {
    '0,0': { u: 'https://school.edu/schedule', l: 'Schedule', d: 'Bell times' },
    '0,1': { u: 'https://school.edu/lunch', l: 'Lunch', d: '' },
    '1,0': { u: 'https://school.edu/portal', l: 'Portal', d: '' },
    '1,1': { u: 'https://school.edu/news', l: 'News', d: '' }
  }
};

function hashFor(state) {
  return Buffer.from(JSON.stringify(state), 'utf8').toString('base64')
    .replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');
}

test('the printed PDF is one A4 page with four scannable codes', async (t) => {
  if (!fs.existsSync(CHROME)) return t.skip('Chrome not installed');
  buildSite();

  const server = spawn('python3', ['-m', 'http.server', String(PORT)], { cwd: SITE, stdio: 'ignore' });
  const tmp = fs.mkdtempSync(path.join(os.tmpdir(), 'massqr-'));
  try {
    await new Promise((r) => setTimeout(r, 1500));
    const pdf = path.join(tmp, 'sheet.pdf');
    const url = `http://localhost:${PORT}/tools/mass-qr/#s=${hashFor(STATE)}`;
    execFileSync(CHROME, [
      '--headless', '--disable-gpu', '--no-sandbox', '--no-pdf-header-footer',
      '--virtual-time-budget=6000', `--print-to-pdf=${pdf}`, url
    ], { stdio: 'ignore' });

    assert.ok(fs.existsSync(pdf), 'PDF was produced');

    // Page count: Chrome writes an uncompressed page tree, so /Count is readable.
    const raw = fs.readFileSync(pdf);
    const counts = [...raw.toString('latin1').matchAll(/\/Count\s+(\d+)/g)].map((m) => +m[1]);
    assert.equal(Math.max(...counts), 1, 'exactly one page');

    // A4 portrait at 72dpi is 595x842pt; allow a point of rounding either way.
    const png = path.join(tmp, 'sheet.png');
    execFileSync('sips', ['-s', 'format', 'png', pdf, '--out', png], { stdio: 'ignore' });
    const img = PNG.sync.read(fs.readFileSync(png));
    const ratio = img.height / img.width;
    assert.ok(Math.abs(ratio - 842 / 595) < 0.02, `A4 aspect ratio, got ${ratio.toFixed(3)}`);

    // Every code must still scan after going through the print pipeline. jsQR
    // finds one code per call, so each quadrant is cropped and decoded alone.
    const found = [];
    const halves = [[0, 0], [1, 0], [0, 1], [1, 1]];
    for (const [qx, qy] of halves) {
      const w = Math.floor(img.width / 2), h = Math.floor(img.height / 2);
      const buf = new Uint8ClampedArray(w * h * 4);
      for (let y = 0; y < h; y++) for (let x = 0; x < w; x++) {
        const si = ((y + qy * h) * img.width + (x + qx * w)) * 4;
        const di = (y * w + x) * 4;
        buf[di] = img.data[si]; buf[di + 1] = img.data[si + 1];
        buf[di + 2] = img.data[si + 2]; buf[di + 3] = 255;
      }
      const res = jsQR(buf, w, h);
      if (res) found.push(res.data);
    }
    assert.deepEqual(found.sort(), Object.values(STATE.tiles).map((t2) => t2.u).sort());
  } finally {
    server.kill();
    fs.rmSync(tmp, { recursive: true, force: true });
  }
});

## Self-Review

**Spec coverage.** Every spec section maps to a task: routing → 3; state and serialization → 4; layout → 3 and 5; editing → 6; grid resize → 7; print → 9; shared renderer → 2; verification → 1, 5 and 9. The spec's file table is fully covered, with `test/` added because the spec asked for re-runnable verification and the repo had no harness.

**Deviations from the spec, deliberate:**
- The spec put the caption-size table under "State"; it is implemented as `CAP_MM` in Task 5 with those exact millimetre values.
- Per-tile quiet zone is 0, because the 4mm grid gap already separates codes. The spec did not settle this. Task 9's PDF decode is the check on that call; if codes fail to scan, raise it to 1-2 modules.
- Grid is capped at 6×6 (`MAX`). The spec gave no bound, and unbounded rows would produce codes too small to scan.

**Open spec questions, unresolved and deliberately left to the executor's first run:**
- Naming (`mass-qr` / `/qrs`) is used throughout. Changing it later means touching Tasks 3's paths plus `netlify.toml`.
- The edit-mode overlay is implemented as specced — `min-width: 220px` with `z-index`, overflowing neighbours.
